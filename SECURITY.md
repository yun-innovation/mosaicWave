# Security policy

mosaicWave is an AI-assisted v0.1 project. Review it before exposing it to the internet, and put it behind HTTPS.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue.

- Use GitHub's "Report a vulnerability" (private security advisory) on this repository, or
- email info@yun-inno.com.

Include the version, the platform, the steps to reproduce and the impact. Do not include real photos, passwords or personal data. We aim to acknowledge a report within a few days. This is a small project, so there is no guaranteed fix time.

## Supported versions

Only the latest release is supported.
